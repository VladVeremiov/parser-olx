# OLX scraper: «Дитячий одяг»

Тестове завдання: зібрати 500 оголошень з категорії «Дитячий одяг» на OLX.ua
у SQLite-таблицю: ID, заголовок, опис, URL, ім'я автора, номер телефону.

## Результат

- В базі **498 з 500** оголошень (2 сторінки не відкрилися, ймовірно, оголошення зняті).
- Номер телефону є у **59** оголошень. В решти його немає: у більшості продавців
  кнопки «Показати телефон» немає взагалі, а частину номерів OLX не показав
  через антифрод-обмеження (див. нижче).

## Інструмент

Скрипт на **Python + Playwright**. Він підключається до браузера Chrome,
у якому я вручну увійшов в акаунт OLX (без входу OLX не показує номери).

## Як це працює

1. Скрипт відкриває сторінки списку категорії (`?page=1, 2, 3...`) і збирає
   посилання на оголошення. Для залогіненого користувача на сторінці 40 оголошень,
   тому для 500 посилань знадобилось 13 сторінок.
2. Відкриває кожне оголошення і бере заголовок, опис, ім'я автора та ID.
3. Якщо є кнопка «Показати телефон», натискає її і читає номер.
4. Записує рядок у SQLite (`data/olx.db`). Повторний запуск не створює дублів
   і продовжує з місця зупинки.
5. Між запитами робить випадкові паузи, при помилці повторює до 3 разів.

## Антифрод і ліміти

- Після кількох десятків натискань кнопки телефону OLX перестає показувати номери
  і виводить повідомлення про «підозрілу активність». Скрипт це розпізнає і зупиняє
  натискання, решта полів збирається як зазвичай.
- Недостаючі номери добирались окремим скриптом `retry_phones.py`: по 10 натискань
  за запуск, з паузами в кілька годин. Обходити захист (проксі, інші акаунти)
  я не намагався.

## Таблиця `ads`

| Колонка | Опис |
|---|---|
| `id` | ID оголошення на OLX (первинний ключ) |
| `title` | заголовок |
| `description` | опис |
| `url` | адреса сторінки |
| `author_name` | ім'я автора |
| `phone` | номер у форматі `+380XXXXXXXXX` або `NULL` |

## Запуск

```powershell
pip install -r requirements.txt
playwright install chromium

# окремий Chrome з портом налагодження, в ньому вручну увійти на olx.ua
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="data\chrome_profile"

python main.py               # повний збір
python retry_phones.py       # добір номерів
pytest -v                    # перевірка бази
```

## Персональні дані

База містить імена і номери приватних осіб, тому файл `data/olx.db` не
викладається в репозиторій і передається окремо.
